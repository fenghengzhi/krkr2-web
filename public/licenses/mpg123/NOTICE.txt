wasm-wrapper-8f2428c1-source.tar.gz. Unrelated decoder modules and upstream

08247b317163175e62035893af3ff9e71a5dfefd. Complete corresponding source,

https://github.com/madebr/mpg123/tree/08247b317163175e62035893af3ff9e71a5dfefd

The wrapper archive retains the upstream Makefile/build.js and package
lockfiles. For the upstream rebuild use that fixed repository, initialize
its recorded submodules, install its build dependencies and Emscripten, and
follow Makefile targets mpg123-configure and mpg123-decoder. No engine or
game source is required to rebuild the decoder. The application dynamically
imports this separate module; replacing the npm package with a compatible
modified build and rebuilding the application with npm ci / npm run build
relinks the application without changing its game logic. There is no binary
signature check that restricts such replacement. npm ci, including with
--ignore-scripts, installs the same pre-corrected file dependency. There is
no application postinstall hook.
