# 第 132 批存档缩略图、剧情文本和声音音量

## 存档缩略图

原 KAG 在写入带缩略图的书签时，用 `Layer.stretchCopy` 把游戏画面缩小，再把剧本和变量附在 BMP 后面。Web 现在按原版处理完整、正向、全不透明度复制时的默认线性和三次滤镜。两种滤镜分别使用三角形和二次钟形权重，按源矩形边缘折返取样。横向算出的颜色及遮罩先舍入到字节，再参与纵向计算。同一位图上的重叠缩放也按原版的列顺序读取。大图缩放可在处理过程中响应停止。[原版滤镜](https://github.com/krkrz/krkr2/blob/dec49af97e174d31059c3ccd7efc700ba3c6b788/kirikiri2/branches/2.32stable/kirikiri2/src/core/visual/Resampler.cpp#L447) · [Web 缩放](../../src/engine/graphics/copy-resampler.ts)

原版 SDK 和 Web 共用 11 项观察，覆盖放大、缩小、重叠、取子矩形、两次舍入及图层绘制错误。浏览器使用原 KAG 模板保存一张带单像素竖条的画面，检查 320 × 240 的 24 位 BMP 的文件头与每个像素，再刷新页面，用游戏自己的读档函数恢复剧情变量。[共享图层脚本](../../tests/helpers/thumbnail-stretch.ts) · [实际书签验收](../../tests/browser/kag-thumbnail.spec.ts)

## 剧情和声音

普通 `[emb]` 对表达式文字中的每个左方括号转义。玩家名字里的 `[r]` 因而能原样进入消息与历史记录。表达式读取下一字符或装入新剧本后，引擎从回调结束时的实际位置续读。作者定义的同名宏仍能执行宏体里的标签。新增 8 个原版共享场景，另在原 KAG 模板里用两次实际点击推进剧情，核对显示文字、等待状态与历史。[解析器](../../src/engine/kag/parser.ts) · [游戏剧情验收](../../tests/browser/kag-embedding.spec.ts)

原版 Wave 先依次合并单轨音量、第二音量、全局音量和静音，每次都做整数截断，再查百分档位对应的衰减量。例如在其他音量全开时，单轨音量 50000 对应 −15.05 dB，振幅约为满幅的 17.7%。声像只衰减一侧。新验收使用已知左右采样值的立体声，按 13 组音量与声像输入比较软件混音输出。Windows 原版另外核对脚本赋值后的读数。原版声卡输出的实际采样仍待取得。[Wave 混音](../../src/engine/media/wave-audio.ts) · [独立预期](../../tests/helpers/wave-gain.ts) · [浏览器双声道验收](../../tests/browser/wave-gain.spec.ts)
