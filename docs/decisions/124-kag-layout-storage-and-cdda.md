# 124　原版游戏排版、图像查找与 CD 音轨

## 发行样例的菜单与分页

第 122 批在 Chromium 和 Firefox 均完成了 32 项原版 KAG 模板及发布兼容验收，包括剧情推进、存读档和转场。另一个未经修改的发行样例 `kag3_intro.xp3` 暴露了排版差异。Firefox 在首次菜单第三个链接出现前停在背面消息层的自动分页。Chromium 已能显示三个链接并进入第一条路线，打印最后一个词时多出一次自动分页，随后才到剧本显式的 `[p]`。[第 122 批托管报告](https://github.com/fenghengzhi/krkr2-web/actions/runs/45482636479)

样例指定的 `MS PMincho` 属于衬线字体。浏览器缺少同名字体时，过去会改用无衬线字体，影响换行和每页容纳的文字。本批保留游戏指定字体的优先级，为这个已知家族选择衬线后备。实际能否走通菜单和两条剧情路线，由同一原包的浏览器验收判定。[微软字体资料](https://learn.microsoft.com/en-us/typography/font-list/ms-pmincho) · [原包路线](../../tests/browser/kag-intro.spec.ts)

Windows 参考作业核对同一 XP3 及解出的原文件，用外部观察脚本执行原入口，保存第一次菜单选择或自动分页时的字体和消息层状态。浏览器仍直接导入 XP3，检查可点击的三个原链接以及剧情、书签和退出。Windows 的首次版面观察与浏览器的完整交互路线分别记录。[原版版面观察](../../tests/probes/kag-intro-sdk.ts)

## 图像加载和停止游戏

查找可选的遮罩与省份图时，旧版会把集合中的普通文件逐个作为候选包打开。如果宿主只能提供整文件读取，就会重复读取大图，还可能把无关文件的读取错误带进当前图像加载。可选搜索现在使用已知的包、明确声明的包和能按范围探测的资源。普通存储查找仍能按内容识别只有整文件读取接口的改名包，显式 AutoPath 上的坏包仍会报错。缓存只保留成员的规范名称，保存或挂载替换时会重建。测试覆盖无关文件读取失败、只读整文件输入、改名包和命名空间变化。[存储回归](../../tests/conformance/lazy-archives.test.ts)

图像验收在实际的 PNG 拉取解码器上挂起读取，检查资源替换后旧结果能否错误地进入缓存。连续失败后的重试先恢复图像大小，再恢复图层几何。遮罩尺寸错误、已经写出的扫描行、未完成的透明度和缓存命中均继续检查。另修正在打开 ZIP 期间按停止后残留的初始画布。[缓存替换](../../tests/integration/processed-image-cache.test.ts) · [PNG 失败恢复](../../tests/helpers/png-stream-consumer-fixtures.ts) · [ZIP 停止与重开](../../tests/browser/zip.spec.ts)

## 菜单光标

全屏游戏弹出同一窗口的菜单时，浏览器可能向画布发送 `mouseleave`，即使玩家没有移动鼠标。旧版会把这个事件当成新的鼠标位置，从而丢掉脚本在菜单中设置的光标。本批按弹出菜单的所属窗口识别这次遮盖，玩家实际移动、点击或滚动时仍交由物理鼠标接管。验收覆盖全屏菜单关闭、跨窗口移出和恢复后的光标。[菜单光标验收](../../tests/browser/menu-cursor.spec.ts)

## CUE 光盘音轨

游戏能用原有脚本 `CDDASoundBuffer.open("2")` 或 `open("D:1")` 选择曲目。单个导入的 CUE 默认使用 D 盘，多盘可由嵌入播放器的宿主在 `cddaDiscs` 中配置盘符与 CUE 路径。曲目文件相对于 CUE 的目录解析，支持归档内的音频。轨道从 INDEX 01 开始，按每秒 75 个 CD 帧定位。CUE 的文件内容目前支持 PCM WAVE、Vorbis 及 2352 字节扇区的原始音频。现有音频文件直接打开的用法继续支持。[CUE 轨道处理](../../src/formats/audio/cue.ts) · [音频存储](../../src/engine/storage/cdda.ts)

Session 验收用左右声道和相邻曲目均不同的 PCM 检查选轨、采样位置、循环与重新打开。浏览器从 XP3 启动原有 TJS 接口，通过 AudioWorklet 输出声音，停止后检查 Worker 退出。时长与位置沿用 Web 播放器扩展，物理光驱的设备行为仍在覆盖范围之外。[Session 测试](../../tests/integration/cdda-disc.test.ts) · [浏览器验收](../../tests/browser/cdda-disc.spec.ts)
